`jvmMain` contém os arquivos de código para o alvo desktop, que usa Kotlin/JVM.

`androidMain` contém os arquivos de código Android e usa Kotlin/JVM.

`iosMain` contém código Kotlin para iOS e usa Kotlin/Native.

`jsMain` contém código Kotlin específico para JavaScript e usa Kotlin/JS.

`wasmJsMain` contém código Kotlin específico para Wasm e usa Kotlin/Wasm.
