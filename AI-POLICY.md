# Política de uso de IA

A IA é uma ótima ferramenta. Porém, pedimos que siga estas regras para garantir a qualidade do código e das discussões:

1. Sempre informe em pull requests e issues se você usou IA.
2. Sempre teste o código antes de abrir um pull request. Não queremos testar código gerado por IA por você.
3. Ouça as pessoas, não as máquinas. Quem contribui com o CloudStream conhece o código melhor que uma IA.
4. Você deve ser capaz de explicar e corrigir qualquer código que enviar. Fazemos revisões detalhadas e rejeitamos contribuições de baixo esforço.
